1 Overview

This document defines the live, machine-readable data dictionary and datasets register for the hs2cycle project and RailActive application.

The register standardizes data structures, variable names, units, and licensing across all active datasets (North-South Corridor, custom GPX re-alignments, OS OpenRoads, DfT STATS19 road safety, OpenStreetMap active travel infrastructure, and the National Cycle Network), while tracking dependencies for forthcoming datasets (trip attractors, LCWIPs, OSMRN/PSGA, and OS NGD pavements).

All underlying schemas are version-controlled and available as machine-readable files:

  • data/datasets_overview.csv: High-level dataset catalog and status
  • data/data_dictionary.csv: Full variable schema and technical definitions
  • data/data_dictionary.json: Web-ready JSON format consumed by the frontend

3.1 North-South Active Travel Corridor (v1 / v2)

The central spinal active travel corridor running along the HS2 civil engineering alignment from London through the Midlands to Liverpool and Manchester, incorporating regional arterial links.

Table 5: DfT STATS19 Collisions Variable Dictionary
Variable Type Description Values / Units Notes
collision_index string Unique national collision reference number Text (13-character string) Primary key for road casualties
collision_year integer Year collision occurred YYYY (e.g. 2023) Annual reporting period
date string Date of collision Date (YYYY-MM-DD) Standard ISO format
time string Time of collision Time (HH:MM) 24-hour clock
collision_severity string Maximum severity of any casualty involved Categorical (‘Fatal’, ‘Serious’, ‘Slight’) Key road safety performance metric
number_of_vehicles integer Number of motorized and non-motorized vehicles involved Positive integer (>= 1) Measure of multi-vehicle involvement
number_of_casualties integer Total casualties resulting from the collision Positive integer (>= 1) Direct injury count
speed_limit integer Posted permanent speed limit at collision site mph (20, 30, 40, 50, 60, 70) High-speed rural lanes correlate with severity
road_type string Road layout at collision location Categorical (‘Single carriageway’, ‘Dual carriageway’, ‘Roundabout’, ‘One way street’) Identifies junction vs link risk
light_conditions string Natural and artificial illumination state Categorical (‘Daylight’, ‘Darkness - lights lit’, ‘Darkness - no lighting’) Evaluates unlit rural road risk
weather_conditions string Atmospheric weather state at collision time Categorical (‘Fine no high winds’, ‘Raining’, ‘Fog or mist’, ‘Snowing’) Environmental risk modifier
road_surface_conditions string Pavement surface condition Categorical (‘Dry’, ‘Wet or damp’, ‘Snow’, ‘Frost or ice’) Friction / skid risk factor
urban_or_rural_area string DfT urban/rural classification Categorical (‘Urban’, ‘Rural’) Based on settlement population thresholds

4 Forthcoming & TBC Datasets

    • Scope: Primary and secondary schools (Get Information About Schools / GIAS) and allocated residential and commercial sites within the 5 km study area to model first- and last-mile demand.

    • Status: TBC

    • Status: TBC
    • Lead / Action: Project Team / PSGA Licencing

    • Status: TBC
    • Lead / Action: Project Team / Ordnance Survey
    • Scope: Dedicated pedestrian pavement geometry, effective footway widths, and severance barriers from the OS National Geographic Database.
